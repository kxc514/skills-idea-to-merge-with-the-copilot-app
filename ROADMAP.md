# Mona's Bookmark Manager

A focused roadmap for making it easier to save, organize, and protect Mona's bookmarks.

| Area | Item | Type | Priority |
|---|---|---|---|
| Discovery | Search & filter bookmarks | 🚀 | High |
| Editing | Edit a bookmark | 🚀 | Medium |
| Organization | Tags or folders | 🚀 | Medium |
| Portability | Import & export bookmarks | 🚀 | Medium |
| Data integrity | Duplicate slugs on re-add | 🐞 | High |
| Validation | Empty-URL validation | 🐞 | High |
| Data safety | Bookmarks lost when localStorage is cleared | 🐞 | High |

## 🚀 Planned features

- 🔖 Search & filter bookmarks — priority: high
- ✏️ Edit a bookmark — priority: medium
- 🏷️ Organize bookmarks with tags or folders — priority: medium
- 📦 Import and export bookmarks — priority: medium

## 🐞 Known bugs & risks

- 🐞 Duplicate slugs can be created when a bookmark is re-added — priority: high
- ⚠️ Empty URLs may be accepted without validation — priority: high
- 💾 Bookmarks can be lost if browser localStorage is cleared — priority: high
